# Complementos de Home Assistant para Kalena

| Complemento | Qué hace |
|---|---|
| [Kalena Letras](kalena_letras/DOCS.md) | Pone con IA el tiempo de cada palabra a las letras de tu Jellyfin, para verlas como karaoke en Kalena. |

## Instalación

En Home Assistant: **Ajustes → Complementos → Tienda de complementos → ⋮ → Repositorios**, y añade:

```
https://github.com/RubenGB99/kalena-addons
```

Este repositorio solo contiene los complementos. No lleva claves ni datos personales: la clave de
API de Jellyfin se escribe en la configuración del complemento y se queda en tu Home Assistant.
